# 16x16zombies
tile based zombie game

Collect coins and reach the flag as quickly as you can. If you touch the zombies you have a fraction of a second to escape before you die.

The game is written entirely in python using the community edition of pygame.

The controls are either WASD or the arrow keys, whichever you prefer.

All assets drawn in adobe photoshop.

The game art uses the same 16 by 16 pixel art used in minecraft to fit in the "retro" brief of this weeks terra projects. The font is also an attempt to match the theme. With more time I would of created a simple 8 bit tune to play quietly in the background.
